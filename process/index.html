사진 상담 후 작업은
이렇게 진행됩니다

사진을 보내주셨다고 바로 공사를 결정해야 하는 것은 아닙니다. 수한공간은 먼저 사진으로 상태를 확인하고, 부분 보수로 가능한지 방문 확인이 필요한지, 전체 공사가 나은 상황인지 차분히 안내드립니다.

바로 결정하지 않으셔도 됩니다.
먼저 상태를 보고 가능한 방법과 필요한 범위부터 안내드립니다.
```
사진 상담 시작

사진 3장을 보내주시면 1차 확인에 도움이 됩니다

전체 공간 사진 1장, 문제 부위 가까운 사진 1장, 옆에서 본 상태 사진 1장을 보내주시면 더 정확하게 볼 수 있습니다.

💬 카카오톡으로 사진 보내기 📋 사진 체크리스트 보기 📞 작업별 전화번호 보기
```
진행 순서

사진 상담부터 작업 마감까지 6단계로 진행합니다

모든 현장이 같은 방식으로 진행되는 것은 아닙니다. 다만 수한공간은 고객이 부담 없이 상태를 확인하고 판단할 수 있도록 아래 순서로 안내드립니다.

```
1

사진과 지역을 보내주세요

전체 공간, 문제 부위, 옆에서 본 상태 사진과 함께 지역, 원하는 작업을 남겨주세요.

2

상태를 1차로 확인합니다

타일 들뜸, 깨짐, 방수 의심, 실리콘 벌어짐, 수전·환풍기 상태 등을 사진으로 먼저 확인합니다.

3

가능한 방법을 안내드립니다

부분 보수, 부분 교체, 덧방, 전체 철거, 방문 확인 중 어떤 방향이 맞을지 1차로 안내합니다.

4

방문 확인 여부를 판단합니다

사진만으로 부족하거나 방수·바탕면·누수 가능성이 있으면 방문 확인이 필요할 수 있습니다.

5

견적과 일정을 조율합니다

작업 범위, 자재, 철거 여부, 일정, 현장 조건을 정리한 뒤 가능한 범위의 견적을 안내합니다.

6

작업 후 마감 상태를 확인합니다

작업 범위에 맞게 시공하고, 마감 상태와 사용 시 주의사항을 함께 안내드립니다.

사진 상담은 계약을 강요하는 절차가 아닙니다

사진 상담은 현재 상태를 이해하고 가능한 방향을 확인하기 위한 과정입니다. 바로 공사를 결정하지 않으셔도 됩니다. 전체 철거가 필요한지, 부분 보수로 가능한지, 방문 확인이 필요한지부터 먼저 안내드립니다.

```
방문 확인 기준

사진만으로 어려운 경우에는 방문 확인이 필요할 수 있습니다

사진으로 많은 부분을 확인할 수 있지만, 모든 현장을 확정할 수 있는 것은 아닙니다. 아래 상황은 현장에서 직접 확인해야 더 안전하게 판단할 수 있습니다.

```

타일 들뜸 범위가 넓은 경우

한 장 문제가 아니라 주변까지 들뜸이 이어져 있으면 바탕면 상태와 접착 상태 확인이 필요합니다.

누수나 방수 문제가 의심되는 경우

아래층 누수, 물고임, 곰팡이, 바닥 틈이 동반되면 방수층 상태를 함께 확인해야 합니다.

자재 매칭이 필요한 경우

단종 타일, 색감 차이, 규격 차이가 있는 경우 현장 확인 또는 유사 자재 안내가 필요할 수 있습니다.

도기·수전·환풍기 부속 상태가 불확실한 경우

기존 부속, 배관 위치, 전기 배선, 설치 공간에 따라 단순 교체가 어려운 경우도 있습니다.

철거 범위가 달라질 수 있는 경우

부분 철거로 가능한지, 주변 마감까지 손봐야 하는지는 현장 상태에 따라 달라질 수 있습니다.

작업 공간 조건 확인이 필요한 경우

엘리베이터, 주차, 보양, 소음 안내, 자재 반입 조건에 따라 일정과 작업 방식이 달라질 수 있습니다.

```
작업 전 준비

작업 전에는 이 부분만 확인해주시면 좋습니다

현장 조건이 미리 정리되어 있으면 작업이 더 수월하게 진행됩니다. 모든 준비가 완벽하지 않아도 괜찮지만, 아래 내용은 상담 시 함께 확인합니다.

```

작업 공간 주변 정리

욕실장 위 물건, 현관 주변 신발, 베란다 짐처럼 작업에 방해되는 물건은 가능한 범위에서 정리해주시면 좋습니다.

주차 가능 여부

공구와 자재를 옮겨야 하므로 주차 위치, 경비실 안내, 방문 차량 등록 여부를 미리 확인하면 좋습니다.

관리사무소 안내 필요 여부

소음이 있는 작업, 철거, 타공, 욕실 공사 등은 아파트 관리사무소 안내가 필요한 경우가 있습니다.

제품 준비 여부

수전, 환풍기, 양변기, 세면대처럼 고객이 제품을 준비한 경우 모델명과 사진을 함께 보내주시면 확인이 쉽습니다.

```
관련 안내

진행 과정과 함께 보면 좋은 관련 페이지입니다

